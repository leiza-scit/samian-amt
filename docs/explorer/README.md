# Samian Research - AMT Explorer

The Explorer of [amt-engine](https://github.com/alpaca-fair-framework/amt-engine) (`docs/explorer/`, MIT licence, see
`LICENSE-amt-engine` and `js/LICENSE`), adapted for samian-amt: three chains of the Samian Research data, the reasoning of the
Academic Meta Tool in the browser, no server.

What the page offers: chain A, B, C; reasoning on and off; labels (on selection, names and weights, weights only, none); a legend of the node colours
(bottom right, foldable); details of the chain and of a clicked node or line (icon in the bar); About panel with logos (icon in the bar);
full screen; downloads as Turtle (with inferred statements and inverse roles), Cypher (the graph as shown, for Neo4j 5), PNG and SVG;
a switch for the inferred lines only; nodes can be dragged; a link that remembers chain, reasoning, labels and the dragged positions (`?ttl=chain-A.ttl&reasoning=on&labels=weights&generic=1&only=inferred&pos=x,y;...`).
The picture shows one direction only; the generic role `reaches` is hidden unless the legend switch is on.

Static files (adapted by hand): `index.html`, `js/` (`amt-render.js` is rewritten, `amt.js` reads the source string of a statement,
`amt-export.js` has the Cypher export), `assets/`, `vendor/` (unchanged libraries). The logo of mainzed is
`assets/img/mainzed.png` (the page shows the word "mainzed" if the file is missing).
Generated by `python main.py --only explorer`: `data/chain-A.ttl`, `chain-B.ttl`, `chain-C.ttl`, `examples.json`.
Local test: `python -m http.server -d docs`, then open `http://localhost:8000/explorer/`.
