# Mini-AMT Explorer

The Explorer of [amt-engine](https://github.com/alpaca-fair-framework/amt-engine) (`docs/explorer/`, MIT licence, see
`LICENSE-amt-engine` and `js/LICENSE`), adapted for the Mini-AMT.

Static files (adapted by hand): `index.html` (header, chain buttons), `js/` (paths in `amt-render.js` and `amt.js`, inverse roles hidden in
`amt-render.js`), `assets/`, `vendor/` (unchanged libraries). Generated by `python main.py --only explorer`: `data/chain-A.ttl`, `chain-B.ttl`,
`chain-C.ttl`, `examples.json`. Local test: `python -m http.server -d docs`, then open `http://localhost:8000/explorer/`.
